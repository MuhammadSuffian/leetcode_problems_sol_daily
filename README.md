# LeetCode Problems - Daily Solutions 

A collection of LeetCode problems solved on a daily basis, as part of my journey to sharpen my problem-solving and data structures & algorithms skills.

Each day's problem is organized in its own folder, containing the solution and (where applicable) notes on the approach used.

## Repository Structure

Each folder follows the naming convention:

```
Day <N> (<Problem Number>. <Problem Name>)
```

For example:

```
Day 1 (128. Longest Consecutive Sequence)
Day 2 (238. Product of Array Except Self)
Day 3 (347. Top K Frequent Elements)
...
```

Inside each folder you'll typically find:
- The solution file
- (Optionally) a brief explanation of the approach, time/space complexity, or notes

The aim of this repo is consistency: solving at least one LeetCode problem every day to build long-term proficiency in algorithms, data structures, and interview-style problem solving.

Feel free to browse any day's folder to see the problem and its solution. If you're following a similar daily-practice routine, you're welcome to fork this repo and use it as a template for tracking your own progress.

##  Notes

- Solutions prioritize clarity and correctness; some may later be revisited for optimization.
- Problem numbers and names correspond directly to their LeetCode problem IDs, so you can cross-reference them on [leetcode.com](https://leetcode.com/problemset/).
